We are currently enhancing our recommendation system by integrating:  
- **BERT (Bidirectional Encoder Representations from Transformers)** for improved NLP-based recommendations.  
- **SVD (Singular Value Decomposition)** for collaborative filtering-based recommendations.  

As these improvements are still in progress, **you may encounter some errors or inconsistencies** while using the project.
